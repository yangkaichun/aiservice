## 4. 設計概念：**「AI 哨兵」（The AI Sentinel）— 讓癌王無所遁形**

### 4.1 概念（全新，與 v2–v7 零重疊）
> **放射科閱片室是一片黑暗。AI 哨兵在黑暗中掃描每一張 CT，橘色警示亮起的瞬間，就是病患的黃金治療期。**

- **場景**：暗房/戰情室美學——深藍夜空（#0a1628 系）為底，放射科的真實感
- **主角**：PANCREASaver 系統真實操作畫面（references 素材），不是插畫
- **視覺隱喻三件套**（貫穿全站，如 DrDoctor 的筆觸）：
  1. **掃描線**：雷達/CT 掃描光線橫掃章節，進入視野時亮起
  2. **警示框**：橘色鎖定框（reticle）框住關鍵數字/病灶——「AI 鎖定」
  3. **系統畫面**：真實操作畫面（Stone Web Viewer）為主視覺，產品即主角

### 4.2 色系（logo 藍主調）
| Token | 色 | 用途 |
|---|---|---|
| `--ink` | `#0a1628` 深藍夜 | 全站底色 |
| `--brand` | `#295daa` logo 藍 | 主色/卡片/按鈕 |
| `--brand-lt` | `#3d7fe0` 亮藍 | hover/掃描線 |
| `--alert` | `#ec7000` logo 橘 | **唯一警示色**：病灶鎖定框/關鍵數字/CTA |
| `--paper` | `#eaf2ff` 冷白 | 文字/卡片內文 |
| 字型 | 微軟正黑體 / Arial（家族紅線） | |

### 4.3 動態系統（捲動即掃描）
- **首屏**：滿版真實系統影片（Stone Web Viewer 操作錄影剪輯）→ 深藍漸層遮罩 → 白色大字「讓癌王無所遁形」→ 橘色警示框鎖定「92.1%」
- **掃描線轉場**：每個章節進入時，一條藍色掃描光由左至右刷過（IntersectionObserver 驅動）
- **數據雷達**：92.1% / 0.95 / 11:12 / 300+ 以「雷達鎖定」方式逐個彈出
- **互動 CT**：繼承 v4/v7 的 split/WL/WW（紅線：只標註真實病灶）
- **reduced-motion**：全關（家族紅線）

### 4.4 滿版影片策略（三支）
| 影片 | 來源 | 規格 |
|---|---|---|
| ① hero 主影片 | references Stone Web Viewer 操作錄影 → ffmpeg 剪 12s 無縫 loop | 16:9 1080p，MP4+WebM <2MB |
| ② 產品 demo | references 操作錄影 3 支 → 剪 60-90s「AI 鎖定病灶」流程 | 點擊播放，muted 預覽 |
| ③ 掃描光背景 | Remotion/ffmpeg 合成（深藍底+藍色掃描光橫掃+橘色警示閃爍） | 章節背景 loop <1MB |
- poster 首幀 + `prefers-reduced-motion`/2g 降級（家族紅線）
